Sistema de Biblioteca

Funcionamento do Sistema

O Sistema de Biblioteca foi desenvolvido para auxiliar no gerenciamento de livros, usuários e empréstimos. O sistema permite cadastrar informações, consultar registros e organizar o controle dos materiais disponíveis.

As principais rotas e funcionalidades são: Cadastro de Livros, Cadastro de Usuários, Empréstimos e Consultas.

Todos os dados são armazenados em um banco de dados, garantindo maior organização e segurança das informações.

Exemplo de utilização: Um funcionário pode cadastrar um novo livro e posteriormente registrar um empréstimo para um usuário.
