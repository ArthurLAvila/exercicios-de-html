Links em HTML

A tag <a> é utilizada para criar links que permitem a navegação entre páginas, sites ou arquivos. O atributo href define o endereço para onde o usuário será direcionado ao clicar no link.

Os links internos direcionam para páginas do mesmo site ou projeto, enquanto os links externos levam para outros sites na internet.
