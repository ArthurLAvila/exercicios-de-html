Divs e Spans

As tags div e span são utilizadas para organizar e estruturar conteúdos em uma página HTML.

A tag div é um elemento de bloco utilizado para separar grandes áreas do conteúdo.

A tag span é um elemento em linha (inline), utilizado para destacar pequenas partes de um texto.
