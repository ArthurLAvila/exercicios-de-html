Imagem em HTML

A tag <img> é utilizada para inserir imagens em uma página HTML. Os atributos src e alt são essenciais para o seu funcionamento.

O atributo alt é importante para a acessibilidade, pois descreve a imagem para leitores de tela e também é exibido caso a imagem não possa ser carregada.
